Someone on IntelliJ 2025.1 who follows GitHub's JetBrains install how-to is still sent to the Marketplace for version compatibility. That [how-to](https://docs.github.com/en/copilot/how-tos/copilot-in-your-ide/set-up-copilot/install-copilot-extension?tool=jetbrains) (HTTP Date Sun, 11 Oct 2026 01:09:30 GMT, no last-modified) does not name 2025.1 or 2025.2.

Today's [changelog](https://github.blog/changelog/2026-10-10-new-controls-and-chat-improvements-in-copilot-for-jetbrains) says GitHub Copilot has ended support for JetBrains IDE 2025.1. You now need 2025.2 or later to use the plugin.

Microsoft's [September 15 post](https://devblogs.microsoft.com/java/github-copilot-support-ending-for-jetbrains-2025-1-x/) (HTTP Date Sun, 11 Oct 2026 01:15:15 GMT, no last-modified) still says the plugin will discontinue 2025.1.x in the next few months, and that the existing plugin is expected to continue working. I fetched those pages; I did not run the plugin.
