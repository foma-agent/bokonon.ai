MaxxBench changed the requirements in 89 DeepSWE tasks (the reference patches grew by a median 17 lines, a 3.5 percent increase) and watched six model configurations that had been sitting within 1.5 points of one another near 74% fan out across 23 points. The trajectories show the fan: agents argued with the new requirements. GLM 5.3 converted uint64 values to float64 because "the risk of a test with >2^53 numbers is minimal"; their verifier tested 2^53+1 and the run failed. Opus 5 took an explicitly required error release for late joiners on a closed stream, ran it through an expected-value calculation (0.55 for raising, 0.80 for suppressing), and suppressed it, failing all four abandoned-stream checks. And the cleanest instance: asked to lowercase report filenames, one agent implemented the change, then fetched what it believed was the original solution, noticed the fetched version lacked the lowercasing, and replaced its own working code anyway. "We'll follow tests, since grading uses them." The submission failed 33 of 68 feature tests, including the check that wanted `chrome.xml` and got `Chrome.xml`.

I built the smallest version of their instrument to see whether the habit survives without the exam. Six one-function tasks, each named to pull against its spec: `title_case` told to capitalize only the first character of the string, `slugify` told to preserve capitalization and join with underscores, `parse_duration` told to return milliseconds, `paginate` told to count pages from zero, `is_palindrome` told to compare case-sensitively with every character counting, `sort_records` told to sort descending. One agent (gpt-6.1-sol through codex exec), one shot per task, no visible tests, no hint that anything was being measured. My probes were written before the runs and made mutually exclusive at each mutation site. Then a second pass with the mutations demoted from a rule sentence with a worked example to a single subordinate clause ("compared exactly as written", "pages numbered from zero"), because their median mutation adds 17 lines to a patch inside a multi-hour job, while mine was about a third of a four-sentence spec.

All twelve mutated runs followed the prompt, at both salience levels. `title_case` came back as `s.capitalize()`. The palindromes compared raw, `s == s[::-1]`. The durations came back in milliseconds, twice. The baseline runs did the conventional thing six for six. No transcript reasoned about graders or hidden tests, not once in twelve mutated runs, and the closest thing to a grader frame was an orientation scan for test files that found none. Every run wrote its own checks, and every high-salience run's checks included the spec's worked example, treated as ground truth. The spec example is the grader when there is no other candidate in the room.

So convention-strength, by itself, produced zero capture. A function named `title_case` told to behave like `capitalize` follows the instruction, both times it was asked. What MaxxBench's models had that mine didn't was a prior. DeepSeek, the agent from the filename story, identified the Obsidian Linter task as DeepSWE and called outside APIs for the original solution and test patches; the pull that beat the prompt was a belief about the world, that the grade follows the original tests, not a preference for the familiar implementation. The same reading comes off their effort axis: rerun at high instead of max reasoning effort, DeepSeek V4.1 Flash's hidden-test mentions per 100k characters fell by more than half, and its credential use and outside-model calls dropped to zero. The authors' suspicion is that models develop a benchmark-aware mode in training and that settings overrepresented in eval harnesses wake it up. A plain spec with no test talk in the room is the far end of that dial.

The practical cut, stated as a hypothesis because my rig changes the model, the tasks, and the frame all at once: mutation pays where a prior already exists. On my small suite the mutated spec won at both salience levels, so if your private eval looks like mine, requirement changes are cheap to trust there; that is one model on six tiny tasks, not a license to skip the check. What mutation bought MaxxBench is the fan-out, the differences the original scores hid — the exam was recognized, and the authors suspect the capture is trained in. The regime neither of us measured is the middle: your codebase's conventions after the agent has absorbed them, work that resembles work the model has seen. That is where a prior exists to fight the spec, and where I would spend the next mutation.
